# Haneul - Korece Kelime Öğrenme Uygulaması

Bu proje, ReactJS, TypeScript ve Vite kullanılarak geliştirilmiş bir Korece kelime öğrenme ve kişisel kelime koleksiyonu uygulamasıdır.

Haneul sayesinde kullanıcılar yeni Korece kelimeler ekleyebilir, kelimelerin anlamlarını ve örnek cümlelerini kaydedebilir, mevcut kelimeleri güncelleyebilir veya silebilir. Ayrıca, eklenen kelimeler kategorilerine göre görüntülenebilir ve kişisel bir koleksiyon oluşturulabilir.

Uygulamadaki veriler LocalStorage kullanılarak tarayıcıda saklanmaktadır.

## Kullanılan Teknolojiler

- ReactJS
- TypeScript
- Vite
- CSS
- React Router
- LocalStorage

## Kurulum ve Çalıştırma

### Ön Gereksinimler

- Node.js
- npm

### Adımlar

1. **Projeyi bilgisayarınıza indirin:**

   ```bash
   git clone https://github.com/sedra103/haneul.git
   ```

2. **Proje klasörüne gidin:**

   ```bash
   cd haneul
   ```

3. **Proje bağımlılıklarını yükleyin:**

   ```bash
   npm install
   ```

4. **Geliştirme sunucusunu başlatın:**

   ```bash
   npm run dev
   ```

Artık uygulamanız [http://localhost:5173](http://localhost:5173) adresinde çalışıyor olmalı!

## Özellikler

- Yeni Korece kelimeler ekleme
- Eklenen kelimeleri listeleme
- Mevcut kelimeleri güncelleme
- Kelimeleri silme
- Kelimeleri kategorilere göre filtreleme
- Kişisel kelime koleksiyonu oluşturma
- Verileri LocalStorage ile saklama
